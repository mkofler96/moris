How to Run the Tests
For Developers
Collaboration diagram for How to Run the Tests:

To run the unit tests, you must compile the code (see the Compile the Code section).

Afterward, move into the test/bin directory and run the executable: 

cd path/to/MORIS/test/bin
./test-moris.exe

To view additional details about the tests, run the executable with the --success argument: 

./test-moris.exe --success

Additionally, if you would like to run only a particular test, use its name as an argument (this is the title which appears in the TEST_CASE line). For example, to run the test for the diag function only, use the command: 

./test-moris.exe moris::diag
