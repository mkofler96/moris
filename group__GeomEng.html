Detailed Description

This module discusses the functionality of the geometry engine (GE). The GE serves as a query of information about the geometries and fields of interest; where a field can be defined by a level set, a density field, or some other design variable. When asked about a certain geometry or field, the GE will return the queried information directly, or an object containing all the information will be returned.
