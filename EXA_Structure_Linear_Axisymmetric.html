Axisymmetric Problem

Problem Description

This example is a linear elastic problem that determines state of stress of cylinder under a radial pressure load. This example tests the axisymmetric formulation for the constitutive model and IWGs. This example also highlights the use of:

  • Axisymmetric Formulation
  • STK body-fitted meshes

The other basic features of the example are summarized in the Main Features of Example.

Discretization given in mesh, 1st order
