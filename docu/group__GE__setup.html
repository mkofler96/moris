First, a geometry representation (GR) must be created via the factory using one of the following options:

1) Option 1 - Discrete

The use of this option will require a target field to map to during initalization.

2) Option 2 - Discrete

  Where p is a set of user-defined parameters.

The use of this option will require a target field to map to during initalization.

3) Option 3 - Analytic

  Where p is a set of user-defined parameters.

The use of this option does not require a target field as the field is already fully defined.

4) Option 4 - SDF

  Where p is a set of user-defined parameters.

The use of this option does not require a target field as the field is already fully defined.

Once the GR is defined, the GE can be created. The GE takes in a GR along with its associated mesh and stores them in a list.

Next, the GE must perform its initalization step. Depending on the type of the GR, the initalization may result in a projection onto the target field. Regardless, the initalization step sets up the container which holds all the relevant information (referred to as PDV_Type_Info objects) and registers it in a list whose index corresponds to the index of the associated GR.

The target field may be defined in many ways. For example, it may be an analytically defined level set field or a collection of geometric primitives or a signed distance field.

Additionaly, the GE has the ability to evaluate a field given a set of paramaters.
