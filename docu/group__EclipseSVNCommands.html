SVN Commands in Eclipse
For Developers
Collaboration diagram for SVN Commands in Eclipse:

To commit changes to the project, update to the latest version, or synchronize with the latest version:

  1. Open the Project Explorer.
  2. Right click on the project (or on a particular directory or file).
  3. Go to Team.
  4. Select the desired action (Update, Commit, etc.).

Refer to Commit Messages for a discussion on proper commit comments and messages.

Update will update files in your local version of the code that you have not modified. For example, suppose that you checkout revision #100 and make changes to file1.cpp, file2.cpp and file3.cpp. Suppose further that a second developer makes changes to file3.cpp and file4.cpp and commits those changes. Should you try to Update, only the changes to file4.cpp will be updated on your local copy. Then, should you try to commit your modifications, you will be a conflict error related to file3.cpp and you will be prompted to synchronize your version.

Synchronize brings up a new perspective in Eclipse which shows any differences between the repository and your local copy of the code. Here, you can remedy any conflicts that may exist. Afterwards, you may Commit your changes.

Before Committing

Before committing your code to the group's repository, make sure that

  • Your code compiles properly in serial, parallel and with the debug flag ON and OFF.
  • Your test run successfully.
  • There are no doxygen warnings related to what you are committing ( for more on running doxygen, see the Running Doxygen section).
