Face-oriented Ghost Stabilization

Face-oriented ghost stabilization for Incompressible Navier-Stokes

The viscous ghost part of the residual is implemented in IWG_Incompressible_NS_Viscous_Velocity_Ghost, corresponding to the enums IWG_Type::INCOMPRESSIBLE_NS_VISCOUS_VELOCITY_GHOST. The stabilization parameter is described in Stabilization Parameter for Viscous Ghost.

The pressure ghost part of the residual is implemented in IWG_Incompressible_NS_Pressure_Ghost, corresponding to the enums IWG_Type::INCOMPRESSIBLE_NS_PRESSURE_GHOST. The stabilization parameter is described in Stabilization Parameter for Pressure Ghost.

The convective ghost part of the residual is implemented in IWG_Incompressible_NS_Convective_Velocity_Ghost, corresponding to the enums IWG_Type::INCOMPRESSIBLE_NS_CONVECTIVE_VELOCITY_GHOST. The stabilization parameter is described in Stabilization Parameter for Convective Ghost.

The time ghost part of the residual is implemented in IWG_Incompressible_NS_Viscous_Velocity_Ghost, corresponding to the enums IWG_Type::INCOMPRESSIBLE_NS_VISCOUS_VELOCITY_GHOST. The stabilization parameter is described in Stabilization Parameter for Time Velocity Ghost.
