Plane Strain Problem.

Problem Description

This example is a linear elastic problem that determines state of stress of an element using a plane strain formulation. This example highlights the use of the following features:

  • Plane strain formulation
  • STK body-fitted meshes

The other basic features of the example are summarized in the Main Features of Example.

Main Features of Example
Feature Value Comment
Dimensionalty 2D, Plane Strain
Mesh type body-fitted STK mesh from file: cylinder_geometry.e
Material/Phases one
Physics linear elastic static
Dirichlet boundary conditions Nitsche left edge direction 1, bottome edge direction 2
Neumann boundary conditions Pressure ( 0.0, 1.0 ) at top edge
Discretization given in mesh, 1st order

Problem Setup

This is a single plane strain element under uniaxial loading with 1-2 boundary condition type to allow for unrestricted poisson effects in all directions.
