This section details STK_FEM Workflow in MORIS. It shows functional utility of each module as a part of workflow and how each module
interacts/communicates with each other. This workflow is particularly suited for fluid oscillation problem which requires bodyfitted meshing strategy.
Since this workflow does not utilize MIG module, one requires commercial package such as Cubit to define boundary sidesets.

Workflow-Performance

Initializer:

Initialize module takes ADVs, upper bound, lower bound and their indicial notations.

Performer:

Two performers are constructed to solve physics problem. MTK performer generates MTK mesh from STK mesh. STK mesh is generated by MTK mesh pair using Integrated
and Interpolated mesh.
MTK Mesh is then passed on to MDL performer, where it evaluates the model and solve for the problem. IQIs are then communicated to FEM.
