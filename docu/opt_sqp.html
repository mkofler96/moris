Sequential Quadratic Programming (SQP)

SQP is a class of methods which solves the optimization problem by iterating based on a quadratic model of the objective and linearized constraints at each evaluation point. If the problem is unconstrained, this reduces to Newton's method.

MORIS uses SNOPT for its SQP algorithm, and all of the parameter names used by MORIS are the same as those used by SNOPT. For further reference about SNOPT, please see the user guide.

Parameters
Major print level[1]: Controls the amount of output to print each major iteration. Possible options are specified as a binary number of the form XXXXXX (please see SNOPT documentation).
Minor print level[1]: Controls the amount of output during the QP subproblems. Possible options are 0 (no output), >=1 (single line summary), and >=10 (basis factorization statistics).
Print file[0]: Change to >0 to print output to file.
Summary file[0]: Change to >0 to print summary to file.
Print frequency[100]: Every nth minor iteration output is printed to file.
Log frequency[100]: Related to print frequency (to log file).
Summary frequency[100]: Every nth minor iteration the summary is printed to file.
Timing level[3]: Prints CPU times.
Major iterations limit[1000]: Number of allowed major iterations.
Minor iterations limit[500]: Number of allowed minor iterations per major iteration.
Iterations limit[10000]: Number of total minor iterations allowed over all major iterations.
Major step limit[2.0]: Limits the change in variables during the linesearch.
Superbasics limit[500]: Places a limit on the storage of superbasic variables.
New superbasics limit[99]: Controls early termination of QPs.
linesearch type["Derivative linesearch"]: Other option is "Nonderivative linesearch"
Linesearch tolerance[0.9]: Controls accuracy of linesearch.
Function precision[3E-13]: Relative accuracy with which nonlinear functions are computed.
Difference interval[5.5E-7]: Sets the interval for forward differencing.
Central difference interval[6.7E-5]: Sets the interval for central differencing.
Proximal point method[1]: Specifies how to satisfy linear constraints near initial guess. Options are 1 or 2.
Violation limit[10.0]: Limit on maximum constraint violation after linesearch.
Unbounded step size[1.0E18]: Determines unboundedness of linesearch step size.
Unbounded objective value[1.0E15]: Determines unboundedness of objective.
Infinite bound size[1.0E20]: Any upper bound greater than this value is regarded as infinity.
Elastic weight[2.0E4]: Weighting of infeasibilities in the objective of the QP subproblem.
Partial price[1]: Reduces the work required for each "pricing" operation.
Pivot tolerance[3.7E-11]: Guards the basis matrix from becoming singular.
hessian_type["Hessian Full memory"]: Method for storing and updating the Hessian. Set to "Hessian Limited memory" for variables > 75.
Hessian frequency[999999]: For full memory Hessian
Hessian updates[20]: For limited memory Hessian
Expand frequency[10000]: Frequency of anti-cycling procedure
Factorization frequency[50]: Frequency of basis updates
LU factor tolerance[10.0]: Limits size of multipliers in L
LU update tolerance[10.0]: Limits size of multipliers in L during updates
LU density tolerance[0.6 ]: Handles sparsity of LU factorization
LU singularity tolerance[2E-6]: Handles guard against singularity during factorization
lu_pivoting_type["LU Partial Pivoting"]: Related to LU factorization. Other options are "LU Rook Pivoting" or "LU Complete Pivoting" ( both more costly and stable).
Major optimality tolerance[1E-6]: Tolerance for major iterations
Minor optimality tolerance[5E-7]: Tolerance for minor iterations
Major feasibility tolerance[1E-6]: Feasibility with respect to nonlinear constraints
Feasibility tolerance[1E-6]: See minor feasibility tolerance (deprecated)
Minor feasibility tolerance[1E-6]: Feasibility with respect to linear constraints
Verify level[0]: Flag to perform finite difference check on derivatives (default false)
Scale option[1]: Flag for scaling of constraints and variables (default true)
Scale tolerance[0.9]: Affects effectiveness with which constraint matrix is scaled
