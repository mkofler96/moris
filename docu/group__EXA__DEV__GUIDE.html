Documentation of Examples

All examples and benchmarks used in moris should be documented in doxygen. The following structure was adapted from the ABAQUS Benchmarks Manual (https://classes.engineering.wustl.edu/2009/spring/mase5513/abaqus/docs/v6.6/books/bmk/default.htm?startat=ch01s04.html) and should generally be followed:

  1. Problem Description: Brief description of the problem. State what the purpose of this example is (e.g. test specific physics or meshing feature, or the interaction of the two)
  2. Problem Setup: All the numbers go here (mesh size, material parameters, etc.)
  3. Analytical Solution: If there's an analytic solution to the problem, give it here.
  4. Results: If there are any specific results to be expected (e.g. eigenfrequency should always be overestimated compared to analytical solution), this should go here.
  5. Literature: If the example is taken from literature as a specific benchmark or as an analytic problem, list the links and citation here.
  6. Developer Notes: Modifications compared to literature, missing features of the example, or observations that should not be forgotten for later, should go here
