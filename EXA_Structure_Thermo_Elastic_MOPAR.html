Problem Description

This example demonstrates thermal-elastic analysis of multi-material aeroshell element. Aeroshell element consists of aluminum core and ablator on the exterior surface of the structure. The problem is setup to compute displacement field and stress field solutions for an applied thermal loading on aeroshell. Key features of the problem formulation are:

  • Mesh: BodyFitted Mesh
  • Workflow: STK-FEM Workflow

The other basic features of the example are summarized in the Main Features of Problem.

Main Features of Problem
Feature Value Comment
Dimensionality 2D
Mesh type BodyFitted
Optimization Scheme None
Material/Phases Two Al and Ablator
Physics Thermal-elastic analysis static
Dirichlet boundary conditions Nitsche Penalty V = 0.5 at inlet
Neumann boundary conditions none
Discretization Per STK mesh

WorkFlow

Thermo-elastic analysis of aeroshell element is done using STK-FEM workflow. For more details about working of STK-FEM workflow, refer to Workflow module. STK_FEM_Workflow.

Problem Setup

The computational domain is defined as a geometry a multi-material aeroshell element consists of aluminum core and ablator material with their respective thermal-elastic properties. In the current workflow, mesh is defined as a bodyfitted mesh generated in cubit.
