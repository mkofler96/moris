Detailed Description

Workflow is a module showcasing workings of different workflows for various problems. It lists functional utility of HMR, XTK, GEN, MTK, STK, FEM modules within a given workflow. Type of workflow associated to a particular problem is mentioned in OPTParameterList. For any problem, default workflow is HMR-XTK_Workflow.
