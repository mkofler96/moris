Detailed Description

EXA is a library of example and benchmark problems used for the validatation of various implementation aspects, such as physics models, stabilization methods, meshing methods, etc. Further, the example problems are used as an extention to the unit tests, which generally do not require the interaction of multiple modules. Values are for field and geometry values are compared to reference runs to ensure that results do not change. As such, they should be run regularly and after major revisions to any module to catch possible errors.

How the examples should be created and used is explained in EXA_DEV_GUIDE. The examples are sorted by the implementation aspect they are supposed to validate (e.g. "Thermal" for testing the thermal diffusion model).
