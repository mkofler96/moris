Fickian Problem for Linear Diffusion

Problem Description

A Fickian problem is a transient diffusion problem following Fick's second law. A thermal diffusion using the general heat equation classifies as such a problem. The analytical solution to a 1D-problem consisting of a semi-infinite bar with an initial temperature and a prescribed temparature on one of its sides, is known.

This Problem is set up to ensure that the numerical results for the thermal diffusion model match the analytical solution to a satisfiing degree of accuracy.
