Multigrid Implementation

This MSI module provides the information on how to build the prolongation and restriction operators for a multigrid preconditioner using adof information.

This module stores.

  • A list of levels which contain ...
  • A map, mapping dof ids to corresponding mesh ids.
  • Dof type/time per dof id
  • If it is Element/Node/Ghost dof

The graph formed by abstract dofs relates back onto mesh information. Therefore the MSI has to provide a mapping between adofs and the mesh information. Multiple adofs, related to different dof types and time, are allowed to have a connection to the same mesh information.

Adofs are defines as as objects with an Id. Multiple adofs with the same id are allowed to exist on multiple processors. However, an adof id has to be unique on a particular processor. Moreover, an adof with a particular id can be owned by only one processor. A potential linear solver only operates on the owned adofs. A mapping between these owned adofs and the mesh information exists.
