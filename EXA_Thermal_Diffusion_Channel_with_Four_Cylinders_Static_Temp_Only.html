Channel with Four Cylinders Static Temperature only

Problem Description

This example is a diffusion-only version of the advective problems Channel with Four Cylinders Static and Channel with Four Cylinders Transient advection problems. It is meant to provide an easy setup for debugging the advections problems. The basic features of the example are summarized in the table below.

Problem Setup

The computational dommain is defined by a rectangles in which a rectangular physical domain is embedded; see figure below. Four circles representing void are placed within the physical domain. A uniform temperature is prescribed at the left edge of the physical domain. Adiabatic boundary conditions are imposed along all other external boundaries. A heat flux of is imposed along the circular curves. The coarses background mesh has elements. The mesh is refined once along the circles and the domain edges.
